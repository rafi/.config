# GitHub Keyboard shortcuts

## Repositories

| Key | Description |
|-----|-------------|
| Open in codespace | `,` or `⌘` + `⌥` + `,` |
| Open in github.dev editor | `.` or `⌘` + `⌥` + `.` |
| Open github.dev editor in a new tab | `>` |
| Focus secondary search bar | `⌘` + `/` |
| Go to Code | `gc` |
| Go to Issues | `gi` |
| Go to Pull Requests | `gp` |
| Go to Actions | `ga` |
| Go to Projects | `gb` |
| Go to Wiki | `gw` |
| Go to Discussions | `gg` |

## Copilot chat

| Key | Description |
|-----|-------------|
| Open Copilot chat | `shift` + `c` |
| Close Copilot chat | `shift` + `x` |
| Expand/collapse Copilot chat | `shift` + `z` |

## Site-wide shortcuts

| Key | Description |
|-----|-------------|
| Open search bar | `s` or `/` |
| Go to notifications | `gn` |
| Go to dashboard | `gd` |
| Go to your issues | `gi` |
| Go to your pull requests | `gp` |
| Bring up this help dialog | `?` |
| Move selection down | `j` |
| Move selection up | `k` |
| Toggle selection | `x` |
| Open selection | `o` or `enter` |
| Expand and move focus into focused link's hovercard | `⌥` + `↑` |
